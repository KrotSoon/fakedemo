# FakeDemo для CS2

Запись своей «фейковой» демки против ботов: конфиги в стиле CS:GO `_fake.cfg` и плагин FakeMimic (аналог Bot Mimic). Боты повторяют записанные тобой движения, все стартуют одновременно. Демка пишется в обычной CS2 из Steam; HLAE нужен потом, для съёмки.

## ⚠️ Безопасность аккаунта

Плагины (Metamod, CounterStrikeSharp, FakeMimic) работают **только с `-insecure`**: с ними нельзя в матчмейкинг и на серверы Valve.
Лаунчер сам запускает игру с `-insecure`, а после закрытия CS2 сам снимает плагины.
**Не запускай CS2 из Steam, пока лаунчер показывает красную точку.** Если лаунчер закрылся аварийно, запусти `Снять плагины.cmd`.

## Установка

1. Скачай `FakeDemo-<версия>.zip` со страницы **Releases** и распакуй куда угодно, но **не** в папку игры.
2. Запусти `FakeDemo.exe`. Ярлык на рабочий стол создаёт кнопка в ⚙, exe можно закрепить и на панели задач. У exe нет цифровой подписи, поэтому при первом запуске Windows может показать «Система Windows защитила ваш компьютер»: нажми «Подробнее» → «Выполнить в любом случае». Тот же лаунчер без exe запускается через `FakeDemo.cmd`.
3. При первом запуске лаунчер сам найдёт CS2 и твой аккаунт Steam. Если не нашёл, открой ⚙ и укажи их.

Зависимости (Metamod, CounterStrikeSharp, CS2-Bot-Controller, около 100 МБ) скачиваются при первом запуске с плагинами и проверяются по SHA256. Для офлайн-установки есть `FakeDemo-<версия>-full.zip`, в нём всё уже лежит.

## Лаунчер

- **Играть** (или Enter). Лаунчер копирует конфиги, собирает `fd_unfake.cfg` из твоих биндов, ставит плагины и запускает CS2. Когда игра закрывается, он снимает плагины. Под кнопкой написано, что именно будет запущено.
- **Боты повторяют движения.** Это плагины FakeMimic. Если выключить, запустятся только конфиги и игра пойдёт без `-insecure`.
- **Журнал дублей.** Это FakeDirector, список дублей в меню H.
- **Карта.** Карточка под переключателями. Без выбора «Играть» открывает главное меню. Нажми на карточку, и откроется выбор карты: две папки, **Официальные** (все карты из игры) и **Мастерская** (твои подписки), у каждой превью и поиск; Enter берёт первую найденную. Если карта выбрана, «Играть» запускает игру сразу на ней (`exec fd` + `map`; карту из мастерской лаунчер вводит в консоль игры через netcon, когда загрузится главное меню: порт 29121 открыт только пока идёт игра, пароль новый при каждом запуске). ✕ сбрасывает выбор. Превью официальных карт берутся из файлов игры, превью из мастерской один раз скачиваются из Steam в фоне при открытии лаунчера.
- **Статус** внизу окна. Если плагины остались в игре, статус краснеет и появляется кнопка «Снять плагины».
- **Папка записей** и **Обновления**. Новая версия проверяется в фоне, ссылка становится золотой.
- **⚙** открывает настройки: папка CS2, аккаунт Steam, свои параметры запуска, `exec fd` при старте, netcon, пересборка `fd_unfake.cfg`.

## В игре

1. Игра открывается в главном меню (`exec fd` уже выполнен, если он не выключен в ⚙). Введи `map de_mirage` или другую карту.
2. Выбрать команду. Режим `fake` (настройки сервера и бинды) включается сам при входе на карту. Список клавиш: `fdhelp`.
3. `tv_record имя` → момент → `Del`. Демка: `...\game\csgo\имя.dem`.
4. **H**: меню FakeMimic. Record new movement → **1** пишет под именем по умолчанию (`m1`, `m2`…), или напиши своё имя в чат, пока открыт этот экран → назначить запись T/CT-боту → Start all bots.
5. После записи: `unfake` возвращает твои бинды.

**Видеть ботов сквозь стены (плагин FakeXray).** **J** или строка «See bots through walls» в меню H: все боты подсвечиваются контуром сквозь стены (T оранжевым, CT синим) и видны на радаре. Удобно, чтобы потренироваться перед записью. Сама подсветка включается и на время записи движения и дубля. В демку она не попадает.

Карты из мастерской прямо в игре: `ws` показывает пронумерованный список подписанных карт, `ws1`, `ws2` и т. д. загружают карту сразу с `exec fd`. Список обновляется при каждом запуске через лаунчер.
Если карта загрузилась не в режиме fake (бесконечный раунд, респавн), введи `fdserver` **до** добавления ботов (он же включает `fake`).

Важно:
- не вводи `bot_kick`: он выкидывает GOTV, и запись ломается. Убрать ботов: Backspace;
- скорость (`host_timescale`) меняй до `tv_record`;
- имя демки только из латиницы, цифр и `_`.

## Где лежат данные

Всё твоё лежит в `Документы\FakeDemo` и не трогается при обновлениях:

- `recordings\<карта>\<папка>\*.fmr` — записи движений;
- `takes\...\takes.json` — журнал дублей;
- `settings.json` — настройки лаунчера;
- `backup\` — копии `gameinfo.gi` и биндов;
- `last.log` — лог последнего запуска.

Переход со старой папки `fakedemo` (0.5 и раньше):
```
powershell -ExecutionPolicy Bypass -File fakedemo.ps1 migrate -From "D:\...\fakedemo"
```
Записи, оставшиеся внутри игры от старой версии, лаунчер переносит сам при первом снятии плагинов.

## Командная строка

`fakedemo.ps1 play | off | status | cfg | update | uninstall | migrate | on`. Лаунчер делает то же самое.

## Для разработчика

- `src\FakeDemo.sln`: FakeMimic, FakeMimicApi, FakeDirector (.NET 10, CounterStrikeSharp 1.0.378). Версия пакета одна, в файле `VERSION`.
- `tools\build.ps1` собирает dll в `plugins\` и `FakeDemo.exe`, после чего лаунчер можно запускать прямо из репозитория.
- `FakeDemo.exe` (`src\Launcher`) — тонкая оболочка: выполняет `launcher.ps1` внутри своего процесса, чтобы у окна был свой значок и нормально работал ярлык. Собирается компилятором .NET Framework из Windows (`tools\build_exe.ps1`), без SDK. Значок `assets\FakeDemo.ico` рисует `tools\make_icon.ps1`.
- `tools\pack.ps1` собирает `dist\FakeDemo-<ver>.zip` и `-full.zip`.
- HUD меню: исходники в `hud\`, скомпилированные `vxml_c` и `vcss_c` в `game\panorama`. Компиляция: `tools\build_hud.ps1` (нужны Workshop Tools CS2).
- Проверка меню в запущенной игре без человека: `tools\hudcam.ps1`. Он берёт порт и пароль netcon сессии лаунчера из `last.log`, вводит команды и снимает серию кадров окна CS2 в один лист с временем каждого кадра. Пример: `tools\hudcam.ps1 -Commands "fm_menu" -Frames 12 -IntervalMs 40 -Crop "940,500,360,480" -Out shots\open`. Несколько команд передаются одной строкой через `;`.
- Игра не перечитывает изменённый макет или стили до перезапуска, даже при смене карты. Поэтому каждая итерация собирается под новым именем: `tools\build_hud.ps1 -Live -Name fm_menu7`, затем в игре `fm_hud_file fm_menu7; map de_mirage`. `fm_cls <панель> <класс> <0|1>` выставляет класс вручную. Пробные `fm_menuN` удаляет `off`.
- Особенности Panorama: размытие фона пишется как `background-blur: gaussian(6, 6, 1)`, `backdrop-filter` не существует; полный список свойств выдаёт `dump_panorama_css_properties`. Переход с `0s` в одном из состояний делает мгновенными оба направления, поэтому повтор анимации при смене экрана сделан через `@keyframes` и чередование классов `SwapA`/`SwapB`. Панель обрезает всё, что выходит за её рамку (и с `transform` тоже), поэтому въезд и наведение должны помещаться в отступы или в панели с `overflow: noclip`. `:hover` без мыши проверяется временным классом-копией, который включается через `fm_cls`. Кнопки меню нажимаются командой `fm_click <id>` (`bg` — шестерёнка). Скрытый экран не делается `visibility: collapse`: свёрнутая так панель не перезапускает анимацию.
- `tools\list_models.py` обновляет `game\models.txt` после того, как CS2 добавит агентов.

Выпуск версии: поднять `VERSION` → дописать `CHANGELOG.md` → `tools\pack.ps1` → создать GitHub Release с тегом `v<ver>` и приложить оба zip.
Новые зависимости: положить zip в `deps\`, обновить `deps.json` (имя файла, SHA256, новое имя `release`) и выложить их отдельным релизом с этим именем.
